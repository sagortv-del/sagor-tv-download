# সাগর টিভি (Sagor TV)

বাংলাদেশি ও ভারতীয় বাংলা চ্যানেল দেখার জন্য একটি IPTV অ্যাপ।

## ডাউনলোড

📥 [app-release.apk ডাউনলোড করুন](https://github.com/sagortv-del/sagor-tv-download/raw/main/app-release.apk)

## ইনস্টল করার নিয়ম

1. উপরের লিংক থেকে APK ফাইলটি ডাউনলোড করুন
2. ফোনের **Settings > Security** থেকে "Unknown sources" বা "Install unknown apps" অনুমতি চালু করুন (যদি চাওয়া হয়)
3. ডাউনলোড হওয়া APK ফাইলে ট্যাপ করে **Install** করুন
4. ইনস্টল শেষ হলে অ্যাপ খুলুন এবং উপভোগ করুন

## বৈশিষ্ট্য
